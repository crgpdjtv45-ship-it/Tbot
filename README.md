# 🤖 Bybit Statistical Arbitrage Trading Terminal

Институциональный квант-бот статистического арбитража (**Pairs Trading**) для биржи **Bybit** (USDT Perpetual Futures, V5 API) с интерактивным управлением через **Telegram** и встроенным квант-исследователем пар.

---

## ⚡ Новые Возможности

1. **Интерактивный Telegram-терминал:**
   - 📱 Кнопки быстрого доступа: `📊 Статус`, `💰 Баланс`, `🔍 Сканировать рынок`, `📈 Открытые сделки`, `🛑 Экстренный стоп`.
   - ⚡ Закрытие любой конкретной пары в 1 клик прямо из чата.
   - 🛡 Защита доступа по вашему `chat_id`.
2. **Квантовый исследователь рынка (`run_market_research.py`):**
   - Сканирует все секторы (*AI, L1, Layer 2, DeFi, Move-VM*) за 180 дней.
   - Проверяет коинтеграцию, винрейт, просадку и коэффициент Шарпа.
   - Автоматически сохраняет проверенный топ лучших пар в `configs/top_pairs.json`.
3. **Пошаговый ассистент подключения (`setup_assistant.py`):**
   - Проверяет ваши ключи Bybit и отправляет проверочное сообщение в Telegram.

## 🚀 Пошаговое Руководство: Запуск и Подключение

### Шаг 1. Настройка ключей Bybit Testnet и Telegram
Запустите интерактивного помощника:
```powershell
.\.venv\Scripts\python.exe setup_assistant.py
```
- Он предложит ввести API-ключи от [testnet.bybit.com](https://testnet.bybit.com) (бесплатный демо-счет с виртуальными деньгами).
- Предложит ввести токен бота из [@BotFather](https://t.me/BotFather) и ваш Chat ID из [@userinfobot](https://t.me/userinfobot).
- Сразу в реальном времени проверит баланс Bybit и отправит тестовое сообщение в ваш Telegram!

### Шаг 2. Запуск торгового бота
```powershell
.\.venv\Scripts\python.exe main.py
```
Бот начнет отслеживать топ-пары и пришлет меню в ваш Telegram.

### Шаг 3. Управление через Telegram
Нажмите кнопку `menu` или отправьте `/start` вашему боту:
- 📊 **Статус** — текущий статус бота и открытые позиции.
- 💰 **Баланс** — баланс кошелька USDT.
- 🔍 **Сканировать рынок** — сканирование коинтеграции и Z-score в реальном времени прямо по кнопке.
- 🛑 **ЭКСТРЕННЫЙ СТОП** — закрытие всех позиций в 1 клик при форс-мажоре.
